# MediCare – Hospital Visitor Management System

## About the Project
CareTrack is a web-based Hospital Visitor Management System designed to simplify and organise the process of registering, monitoring, and managing visitors in a hospital environment. The system provides an organised way to record visitor information, associate visitors with patients, and track visitor entry and exit.

## Features
- **Visitor Registration:** Register visitors and associate them with a patient, patient ID, and ward.
- **Visitor Pass Generation:** Automatically generate visitor passes upon registration.
- **Active Visitors:** View visitors currently inside the hospital.
- **Visitor Checkout:** Record visitor exits and update visitor status.
- **Visitor Records:** Access and search previously registered visitor records.
- **CSV Export:** Export visitor records for documentation and record-keeping.
- **Dashboard:** Display statistics and an overview of visitor activity.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the website and its functionalities.
